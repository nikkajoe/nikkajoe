## 🖤 Why I Do This

I don't just build apps or design websites.  
I build **messages** — for those who couldn’t speak, or weren’t allowed to.

Each line of code, each pixel, each interface...  
is a reflection of my belief that **tech isn't neutral** — it’s a tool for resistance, memory, and freedom.

I believe that even in a world of censorship,  
we can carve out spaces for voices like **Nika**, **Mahsa Amini**, and **Hadis Najafi**.
